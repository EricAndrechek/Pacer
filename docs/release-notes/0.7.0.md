Pacer looks like a macOS 26 app now — and on macOS 15 it looks exactly like it always has.

## The new design

On **macOS 26 (Tahoe) and macOS 27**, Pacer adopts the system's current design:
buttons, pickers, menus and the toolbar all pick up Liquid Glass. Until now it
did not, and the reason is a detail worth stating once — macOS decides an app's
appearance from the SDK it was built against, not the version you are running.
Pacer was still built against the macOS 15 SDK, so it kept the old look even on
a brand-new Mac. This release changes what it is built with.

**Your data is untouched.** No database reset, no re-import, no re-scan. This
is a minor version because the app looks materially different, not because
anything underneath moved.

**On macOS 15 (Sequoia) nothing changes at all** — that version of macOS has no
new design to draw, and Pacer still runs there from the same single download.
macOS 15 remains the minimum.

## Four things that were broken on macOS 26+ and are fixed

These only affected people already on Tahoe. Each one came from the system
changing behaviour underneath the app rather than from anything Pacer did.

**A second account could be scanned twice.** If you use `claude-swap`, Pacer
checks whether a discovered profile is a folder it already scans, and that
check compared two file URLs. macOS 26 changed how it decides whether a
directory URL ends in a slash, so the same folder stopped comparing equal to
itself and the guard silently stopped working. Totals stayed right — duplicate
turns are caught later by message id — but every file under that folder was
being parsed twice on every scan.

**The Models trend axis was unreadable.** It asks for six date labels across 90
days; macOS 26 drew all ninety, stacked on top of each other.

**Menu-bar tooltips stopped appearing.** Hovering the menu-bar item, and the
rows inside its dropdown, showed nothing. They use AppKit's tooltips again
rather than SwiftUI's, which still work.

**Pacer could steal focus at launch and land on the wrong screen.** Restoring
the dashboard you had left open brought the app to the front over whatever you
were working in, and a dashboard parked on a display that was not currently
connected reappeared somewhere arbitrary instead of where you keep it. It now
hands the front back to the app that had it, and falls back predictably when
its home display is missing.

## Smaller things

Controls sit at the size macOS 26 designs around, rather than being compressed
a step smaller everywhere. The status readout in the toolbar no longer draws a
second pill inside the one the toolbar already draws for it. Cards keep their
edges: macOS 26 made the window background and the card background the same
colour, which had quietly flattened every stacked view.
