Version, update and feedback buttons in plain sight, a "price pending" mark for models Pacer can't price yet, and updates and prices that keep arriving when Pacer's site can't be reached.

## Version, updates and feedback
The dashboard sidebar now has a Feedback row beside Settings, with Pacer's version under them (and download progress while an update downloads). When an update is ready, a "Restart to Update" row appears above them, and the menu-bar menu offers "Update to X — Restart". The old "Relaunch to Update" item reads the same way now.

## Send Feedback
The form is shorter and friendlier: pick Idea, Problem or Something else, type, and send. Files and a picture of Pacer's window attach right in the message box, and an email is there if you'd like a reply. Feedback now goes through pacer.andrechek.com straight to the developer, so it works with crash reports off and without a GitHub account. Only credentials, such as keys and tokens, are removed from what you type, and the form tells you when it removes one.

## New models
When Claude Code uses a model Pacer has no price for yet, its costs now show a small hourglass ("price pending") instead of quietly reading $0. Pacer checks for a price every hour for a week, and past costs update on their own once one is published.

## More reliable updates and prices
- If pacer.andrechek.com can't be reached, Pacer reads the update feed and price list from GitHub instead.
- A failed update download is retried within 30 minutes, not 6 hours.
- Right after an update, Pacer checks once more, so you reach the newest version quickly.

## Smoother
- Quitting is fast again on a busy Mac. It no longer waits for background forecast work the Mac isn't running.
- The first usage reading after launch arrives sooner on a busy Mac.
- Usage polling is steadier when the Mac is under load.

## Privacy
Update checks and price fetches now include Pacer's version and, only while Usage data is on, its anonymous install id. They go only to pacer.andrechek.com, never to GitHub. Pacer still never sends prompts, projects, files, accounts or costs.

**Your data is untouched.**
