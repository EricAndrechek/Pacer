Fewer freezes, especially on a busy Mac, and a daily check that Pacer's numbers still match Claude Code's own.

**If Pacer only runs in your menu bar and you're on 0.8:** quit it and reopen it once so this update installs. After that, updates install by themselves while you're not using Pacer.

## Smoother
- The window and its toolbar no longer redo their work every time Pacer saves.
- Project pages check whether a project's folder still exists in the background, so a slow or disconnected drive can't freeze them.
- Looking up your other logins and Claude Desktop sessions no longer holds Pacer up while it reads the keychain or the disk.
- Recording a freeze no longer causes another one.
- When your Mac is short of memory, Pacer refreshes its local API and its forecasts less often, so it doesn't push out the memory it's using.
- Freezes are written to Pacer's log with where they happened, so the ones that remain can be found.

## A daily accuracy check
Once a day, Pacer compares its totals for your most recent Claude Code sessions with Claude Code's own. From late September to late October, a Claude Code bug left subagent output out of its transcripts, and nothing noticed for weeks. Pacer would now catch that within a day. If the totals ever disagree, Pacer reports only which kind of token, roughly by how much, and the Claude Code version.

## Coming from 0.8?
This release also brings 0.9.0 and 0.9.1:
- Updates download only what changed, a few megabytes instead of about 160 MB.
- If Pacer crashes, it reopens itself in the background about 10 seconds later.
- Updating no longer rewrites your usage history.

## Privacy
The accuracy check sends only the token kind, a rough size of the difference, and the Claude Code version: never counts, sessions or projects. No other new kinds of data are sent. Pacer never sends prompts, projects, files, accounts or costs.

**Your data is untouched.** Coming from 0.8, Pacer upgrades it in seconds on first launch. After that, an older version of Pacer can't open it, so this one can't be downgraded.
