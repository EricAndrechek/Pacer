A `pacer` command for your terminal, pacing that works with the local API off, Claude Desktop's usage on the right account, and a lighter dashboard.

## `pacer` on the command line

Pacer now carries a `pacer` command. `pacer report` shows every rate-limit window for the account you're on, and `pacer gate`, `pacer wait` and the rest are the pacing skill's commands.

- **Homebrew** installs put `pacer` on your PATH.
- **Downloaded** installs: Settings → Integrations → Command line → **Install**. If `/usr/local/bin` is already yours, that's it; otherwise macOS asks once for your administrator password. Pacer keeps the command pointing at the app if you move it.

## Pacing works with the local API off

The pacing skill used to read Pacer only through its local API, which is off by default, so for most people it said "proceeding ungated" and paced nothing. It now reads Pacer's data directly when the API is off, with the same answers either way.

The skill's script is gone: it runs `~/.claude/skills/pacer/pacer <command>` now (or plain `pacer <command>` where it's on your PATH). Pacer updates the installed skill for you. A session that already had the old instructions loaded finds `pace.sh` missing until it reloads the skill.

## Claude Desktop's usage on the right account

Claude Desktop's built-in Claude Code bills Desktop's login, but Pacer counted its turns against whichever account your terminal was signed into. They now go to the account Desktop recorded, including past turns. Totals across all accounts don't change; per-account numbers do.

## Also

- The pace chart re-read every account's history whenever any account's usage was read, about 130 times an hour. It now reads only the account that changed, which cut its background work from minutes an hour to seconds.
- A session's account and model, as the pacing skill asks for them, come back instantly even when your Mac is busy, and sessions from Claude Desktop or a second Claude login are paced on their own account.
- After an account switch, the local API's event stream announces it in under half a second instead of about two.
- Settings showed the local API's port as "7,223", so a copied URL didn't work. It's "7223" again.

**Your data is untouched.** No reset, no re-import.
