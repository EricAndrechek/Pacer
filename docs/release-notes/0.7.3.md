Account switches that show up in about a second, readings for the account you're on that stay fresh, a local API that keeps answering when your Mac is busy, and a Homebrew install.

## Switching accounts shows up right away

After a `/login` or a `claude-swap` switch, Pacer used to notice only on its next scan, which could take a few seconds when you were busy and minutes when you weren't. A brand-new account didn't appear until Pacer had read its usage at least once, which took up to several minutes. Pacer now sees the switch the moment it happens. The dashboard, menu bar, Settings and the local API all move to the new account in about a second, and a new account appears as soon as you sign in.

Until Pacer has read an account's usage, it says "no reading yet" instead of showing 0%. The rate-limit widget used to show a 0% ring there.

## Readings for the account you're on stay fresh

- When Claude Code renewed its login, Pacer could go up to 30 minutes without being able to read your usage. It now picks up the renewed login right away.
- Pacer and `claude-swap` could ask for the same account's usage at the same moment, and both got turned away, leaving the reading 14 minutes old. Pacer now takes `claude-swap`'s readings as its own and stays out of its way.

## The local API keeps answering

With the local API turned on (Settings → Integrations), a slow moment on your Mac could stop it answering every request, including the pacing skill's. Sessions that pace themselves then carried on without a limit, just when it mattered most. The API now answers from numbers it keeps ready in memory, in a few milliseconds, and says how old they are.

## The pacing skill

- It now stops at the safe limit by default: as close to 100% as the age of the latest reading allows. Previously it stopped at 85% unless you set a limit yourself.
- It follows a `/login` switch while a session is waiting, instead of watching the account it started on.

## Install with Homebrew

```sh
brew install --cask ericandrechek/tap/pacer
```

Pacer still updates itself; Homebrew picks up each new version too.

## Also

- The dashboard could freeze for a moment while Pacer checked whether a usage limit had reset early. That check now runs in the background, and only when it can matter.
- While Claude Desktop keeps rewriting the shared Claude Code settings file, Pacer checks your login far less often.

**Your data is untouched.** No reset, no re-import.
