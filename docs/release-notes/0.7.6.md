Fixes to `pacer`, the command the pacing skill uses to pause work before a limit and resume after it.

## Your session's model decides which limits apply

Inside a Claude Code session, `pacer gate` with no `--model` used to hold your work to every limit on the account, including a per-model cap your work never touched, so Opus work paused on a full Fable window. It now does what `--model auto` does: it looks up the model your session runs and applies the caps that bind it, and the verdict says what it found. Outside a session nothing changes, and `--model all` still applies every limit.

## `wait` resumes only when the limit has really cleared

A paused session could be released while still at the limit. As other sessions paused, usage slowed, the safe limit rose a point, and `wait` took that for a reset. `wait` now holds the limit that paused you. It resumes when that window resets, when you switch to an account with room, or when usage really drops, and it says which.

## Lanes stay paced through long tasks

`pacer status`, the cheap check subagents run between steps, called a verdict stale after 15 minutes, so long tasks went unpaced. When a verdict is stale, `status` now refreshes it itself: one reader checks Pacer and the rest wait a moment for its answer, so a hundred lanes still cost one check.

## Each session keeps its own verdict

Sessions used to share one pause verdict unless they set `PACE_RUN`, so a test in one session could pause all of them. Each session now has its own, shared with its subagents. `PACE_RUN` and `PACE_STATE` work as before.

## Stop short of the limit by a margin

`--margin N` pauses N points before the safe limit, which still adapts to how fast usage is climbing. A fixed `--cap` replaced that limit. `pacer safecap` prints the limit each window is held to.

## Report a Pacer problem from the command line

`pacer feedback "what you ran, what it printed"` saves the report on your Mac and prints a link to file it as a GitHub issue, pre-filled with the report, the Pacer version and the last verdict. Nothing is sent anywhere. The pacing skill now tells agents to report Pacer problems this way instead of working around them in their notes.

**Your data is untouched.** No reset, no re-import.
