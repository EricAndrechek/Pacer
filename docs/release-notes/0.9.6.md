Prices that arrive from one shared list, and a Pacer that stays responsive and quits cleanly on a busy Mac.

## Prices from one list
Pacer now reads model prices from a single list on pacer.andrechek.com, merged from the public price catalogs every six hours. A new model is priced within hours, every Mac records the same price change on the same day, and the daily download is a few kilobytes instead of almost two megabytes. Pacer only contacts the catalogs itself if that list goes unconfirmed for ten days.

## Steadier on a busy Mac
- The pace card no longer spends seconds re-measuring itself, which could freeze Pacer on a Mac short of memory.
- Quitting stops all drawing first and finishes within seconds; nothing is written after the last save.
- Pacer can no longer crash while writing a malformed number into a report.

**Your data is untouched.**
