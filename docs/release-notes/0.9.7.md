Steadier usage readings when you have several Claude logins, and one update instead of two when newer versions ship while an update is waiting.

## Steadier usage readings
Some Claude logins carry tokens that can't read usage. Pacer used to keep retrying them every hour, which delayed the readings that do work. It now sets them aside after a few refusals and skips tokens that can't read usage at all.

## One update, the newest
When an update had been waiting for a quiet moment and a newer version shipped in the meantime, Pacer installed the older one first and then the newer one. It now waits to download until it's ready to install, so it installs the newest version once. The sidebar shows "Restart to Update" as soon as an update is available.

**Your data is untouched.**
