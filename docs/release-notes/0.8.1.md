Fixes for Ultra accounts, and an easier way to report a problem.

## Report a problem from anywhere

**Report a Problem…** is now in the menu-bar menu and in Settings → Privacy, as well as the Help menu. A report can include a picture of Pacer's window and any files you add.

## Ultra accounts

### Widgets show each window once
The rate-limit gauges and pace chart widgets showed the 7-day window twice on accounts with no 5-hour limit. They now show 7-day and the next window you have, or just 7-day, and the widget's Edit sheet no longer offers a 5-hour window the account doesn't have.

### No empty 5-hour readouts
Account rows in Settings no longer show an empty 5-hour bar, and Settings hides the 5-hour menu-bar chip and alert thresholds when no account has a 5-hour limit.

**Your data is untouched.**
